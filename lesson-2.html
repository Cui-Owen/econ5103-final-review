核心公式与计算决策路由（考前必熟）

1. 外部性与庇古政策（U12）

  • 识别词：MPC / MEC / MSC、Coase bargaining、Pigouvian tax、DWL
    • 关键公式：MSC=MPC+MECMSC = MPC + MECMSC=MPC+MEC；私人点 P=MPCP = MPCP=MPC（产量 QAQ_AQA​）；社会最优点 P=MSCP = MSCP=MSC（产量 QBQ_BQB​）。
    • 庇古税取值点：必须在社会最优产量 QBQ_BQB​ 处取 t=MEC(QB)t = MEC(Q_B)t=MEC(QB​)（勿取 QAQ_AQA​ 处）。
    • Coase 区间：减产至 QBQ_BQB​ 时，最低要求（卖方损失） = 利润缺口 ∫QBQA(P−MPC) dQ\int_{Q_B}^{Q_A}(P - MPC)\,dQ∫QB​QA​​(P−MPC)dQ；最高愿付（受损方收益） = 减少损害 ∫QBQAMEC dQ\int_{Q_B}^{Q_A} MEC\,dQ∫QB​QA​​MECdQ；净剩价值 = DWL。

2. 公共品 2×2 与不对称信息（U12）

  • 四个格子：竞争+排他 = Private；非竞争+排他 = Artificially scarce（MC=0 但定价引发 DWL）；竞争+非排他 = Common pool（公地悲剧）；非竞争+非排他 = Public good/bad（搭便车无法收费）。
    • 信息不对称二分：签约前不知隐藏体质/质量 = Hidden attributes → Adverse selection（逆向选择→市场萎缩失灵）；签约后看不见偷懒或冒险 = Hidden action → Moral hazard（道德风险→需垫付/免赔/纪律）。

3. 劳动统计三率与 `WS/PS` 均衡（U9）

  • 分母别搞混：
Participation=LFPopwa,Unemployment=ULF,Employment=EPopwa\text{Participation}=\frac{\text{LF}}{\text{Pop}_{wa}},\quad \text{Unemployment}=\frac{U}{\text{LF}},\quad \text{Employment}=\frac{E}{\text{Pop}_{wa}}Participation=Popwa​LF​,Unemployment=LFU​,Employment=Popwa​E​
 （气馁退市会人为压低失业率，须同步看就业率）
  • PS 方程：WP=OutputWorker−Real profit per worker\frac{W}{P} = \frac{\text{Output}}{\text{Worker}} - \text{Real profit per worker}PW​=WorkerOutput​−Real profit per worker（平线，取决于生产率 λ\lambdaλ 与 竞争加成 Markup）。
  • WS 移动口诀：
    • 升 PS（加真实工资降失业）：提高劳动生产率（教育培训）或给企业发工资补贴降成本、或加强竞争降 Markup。
    • 下移 WS（真实工资在平 PS 下不变，失业率降）：砍失业救济、移民/托育增劳动力供给、工会发声（Voice effect）增配合。
  • Demand-deficient 失衡：总需求不足偏离至 B 点；理论上可通过“降工资→降成本→降价→扩需求”自动回 X，但现实因“抵触降名义工资、降薪更不敢买、期待再降价推迟耐用品消费”而失灵，需靠宏观刺激。

4. 跨期选择、货币创造与资产负债（U10）

  • 最优借贷/储蓄：预算边界斜率 MRT = 1+r，偏好无差异 MRS = 1+ρ，均衡满足 1+ρ=1+r1+\rho = 1+r1+ρ=1+r。
    • 货币三口径：Broad money=Base money（央行法币）+Bank money（商行放贷创造的存款）\text{Broad money} = \text{Base money（央行法币）} + \text{Bank money（商行放贷创造的存款）}Broad money=Base money（央行法币）+Bank money（商行放贷创造的存款）。放贷直接创造存款。
    • 净值与杠杆红线：Net worth=Assets−Liabilities\text{Net worth} = \text{Assets} - \text{Liabilities}Net worth=Assets−Liabilities；Leverage=Total assetsNet worth\text{Leverage} = \frac{\text{Total assets}}{\text{Net worth}}Leverage=Net worthTotal assets​。资产跌破 1/Leverage1/\text{Leverage}1/Leverage 百分比即导致 Net worth<0⇒Insolvent\text{Net worth} < 0 \Rightarrow \textbf{Insolvent}Net worth<0⇒Insolvent。
    • 两类银行风险：Default risk（贷款收不回）与 Liquidity risk（活期存款挤兑 Bank run 碰上冻结长期贷款）。
    • 信贷配给：委托-代理冲突逼出 Equity + Collateral 门槛，穷人沦为 Credit-constrained 或 Credit-excluded。

跨单元桥接思考题（建议 6 分钟）

⏱ 06:00

请用 Incomplete contracts（不完全契约）与 Principal–Agent（委托-代理） 的统一逻辑，分别两句话解释三个核心现象：

  • (a) 为何健康保险经常出现“Missing market”（健康人买不起甚至干脆不买）？
  • (b) 为何劳动市场即便处于纳什均衡，也总有愿意按现行工资干活却找不到工作的非自愿失业者？
  • (c) 为何无抵押资产的年轻人即使能力出众也常遭到银行拒贷（Credit-excluded），且央行即使把 Cash rate 降到极低也不足以消除这种信贷排斥？
📁 查看参考答案与踩分点⌄

✅ 考试简洁答法（Score-ready）

  • (a) 保险合同无法核实投保人投保后的谨慎驾驶努力（Hidden action → Moral hazard），也无法事先看穿每个人真实隐藏患病风险（Hidden attributes → Adverse selection），迫使保险公司提高保费，最终健康群体拒绝投保，形成缺失市场。
  • (b) 雇用合同同样不完全，企业无法无成本强制测量员工努力；为了维持正的 Employment rent 让失业产生代价，雇主只能把工资定在保留工资之上（WS 与 PS 交点），从而均衡必然保留一批非自愿失业者作为纪律缓冲。
  • (c) 银行（委托人）无法担保借款人（代理人）的项目不失败或资金不被挪用，因此靠要求 Equity（自有股本）与 Collateral（抵押品） 对齐利益。资产匮乏者无法提供充足抵押，只能承受高利（Credit-constrained）或彻底被拒（Credit-excluded）；即便央行降低 Policy/Cash rate 拉低整体基准利率，穷人面临的信贷配给鸿沟（进而加剧不平等）也不会自动抹平（且过低利率还需留意如 SQ4/SQ6 所讨论的资产价格通胀风险）。
