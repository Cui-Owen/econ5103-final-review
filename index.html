微宏观四条贯通主线

课程虽涵盖 15 个单元，底层分析逻辑主要围绕以下四条主线展开：

  1. 约束优化与相切框架（U3 / U6 / U7 / U15）：个人劳动闲暇选择、企业效率工资设定、垄断定价，以及央行的 Phillips 曲线通胀-失业权衡，底层共用同一套分析结构——无差异曲线 / 等利润线与可行边界相切（MRS = MRT）。
  2. 劳动市场与产品市场的联动（U6 + U7 → U9 → U14 → U15）：产品市场的竞争程度决定垄断加成 Markup，进而决定劳动市场水平 PS 线的高度；短期 45° 总需求 AD 下滑会通过生产函数 N=Y/λN = Y/\lambdaN=Y/λ 减少用工，在 WS/PS 图上表现为向左偏离均衡的周期性失业；当总需求过热推高用工、使要求工资高于企业可支付水平时，正向的 Bargaining gap 便会沿着 Phillips 曲线推升通胀。
  3. 金融条件与实体总需求的传导（U10 → U14 → U15）：央行调整名义政策利率 iii（通过 Fisher 关系影响真实利率 r=i−πer = i - \pi^er=i−πe），连同商业银行的信贷与货币创造机制，经由企业投资 I(r)、资产净值与抵押品 Collateral、盈利预期 Π\PiΠ 以及汇率与净出口 NXNXNX 四条路径改变自发总需求，再通过开放有税乘数 kkk 放大为总产出 YYY 的波动。
  4. 财政政策与政府债务的动态反馈（U5 + U8 + U12 → U14 → U15）：税收与外部性在微观部分用于分析收入再分配与效率损失，在宏观部分则表现为自动稳定器（ttt）；衰退期间如果大幅削减政府支出，乘数效应会压低产出 Y 并使税收 tYtYtY 自动收缩，从而削弱实际减赤效果；而降低债务占 GDP 比率的三条路径，则进一步联系到通胀对固定名义债务实际价值的稀释与独立央行的预期管理。
