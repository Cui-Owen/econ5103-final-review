全学期知识贯通主线：微宏观四座核心桥梁

ECON5103 看似跨度 15 个单元，底层其实只复用四套核心分析框架。考场遇到微宏交叉综合题时直接套用以下主线：

  1. 偏好/可行边界统一桥梁（U3 / U6 / U7 / U15）：个人劳动闲暇选择、企业劳动纪律、垄断利润最大化、央行 Phillips 曲线政策抉择，底层全套复用 无差异/等成本/等利润与可行前沿相切（MRS = MRT）。
  2. 劳动与产品市场贯通（U6 + U7 → U9 → U14 → U15）：微观定价加成的 Markup 决定劳动市场水平 PS 线高度；短期 45° 总需求 AD 跌落决定就业人数 N=Y/λN = Y/\lambdaN=Y/λ，对应 WS/PS 上向左偏离均衡的周期性失业；过热推右则生正 Bargaining gap，直接把通胀率沿 Phillips 曲线推高。
  3. 金融与实体乘数传导（U10 → U14 → U15）：央行操控名义政策利率 iii（通过 r=i−πer = i - \pi^er=i−πe）与银行创币规则，经 I(r)、房价净值与抵押 Collateral、企业利润期待 Π\PiΠ、汇率与净出口 NXNXNX 四路注入自发总需求，再经开放有税乘数 kkk 放大为总产出 YYY 波动。
  4. 政府财政与债务联动（U5 + U8 + U12 → U14 → U15）：税收和外部性从微观再分配与效率矫正，升级为宏观自动稳定器（t）；衰退期盲目削支 Austerity 因乘数效应打压 Y 并令税收 tYtYtY 自动塌陷而难降赤字；降债务率的通胀路径则直接联系 Fisher 名义债务稀释与央行 CBI 信任权衡。
