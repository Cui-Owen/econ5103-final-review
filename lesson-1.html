第 1 课：微观基础决策与市场定价

本课涵盖第 1 至第 8 单元的微观基础分析，以及第 11 单元的价格动态模型。前半部分探讨个人与企业在约束下如何选择、博弈效率及分配不平等衡量；后半部分分析企业定价权、完全竞争税收效应，以及价格通过 45° 线收敛或演变为泡沫的机制。

复习层次涉及单元与内容
核心重点Units 2–3（经济租、等成本线与 MRS=MRT）、Units 5 & 7（Gini 与垄断利润 Profit = PS − FC）、Units 8 & 11（税收 DWL 与 45° 价格动态）
背景与次要概念Units 1 & 4（增长背景概念、囚徒困境与纳什均衡文字辨析）

核心公式与解题步骤

1. Economic Rent、比较优势与等成本线（Unit 2）

  • 识别词：next-best option、economic rent、sunk cost、comparative advantage、isocost slope
    • 核心公式：
      Rent=Net benefit(chosen)−Net benefit(next-best)\text{Rent} = \text{Net benefit(chosen)} - \text{Net benefit(next-best)}Rent=Net benefit(chosen)−Net benefit(next-best)
      C=wL+pR⇒等成本线斜率 =−wpC = wL + pR \Rightarrow \text{等成本线斜率 } = -\frac{w}{p}C=wL+pR⇒等成本线斜率 =−pw​
    • 解题步骤：首先将已经支付且不可退回的沉没成本从备选方案中剔除（因为无论选择哪个方案，这笔钱都拿不回来，不影响两方案的差值）；判断比较优势时，计算“每生产 1 单位 X 需要放弃多少 Y”的机会成本比值，放弃更少的一方拥有比较优势；当 w/pw/pw/p 上升、相对劳动变贵时，等成本线变陡，成本最小化组合转向少 LLL 多 RRR 的技术。
    • 核对说明：绝对优势看绝对产量高低，比较优势看机会成本高低；一个人不可能同时在两种产品上都处于比较劣势。

2. 约束优化 `MRS = MRT`、两效应与 Gini 系数（Units 3–5）

  • 识别词：MRS = MRT、income effect、substitution effect、Dominant / Nash / Pareto、Gini
    • 收入效应与替代效应的区分：先看预算线外移且不改斜率的部分——这是 Income Effect（对于正常品，消费与自由时间通常同时 ↑\uparrow↑）；再看相对价格改变导致的预算线斜率变陡——这是 Substitution Effect（闲暇的机会成本变贵，促使自由时间 ↓\downarrow↓）。实际工时的净变化方向取决于两个效应的相对大小。
    • Gini 系数计算公式（Week 2 讲义口径）：
      G=12×平均两两绝对差平均收入(3人样本取 n(n−1)/2=3 对)G = \frac{1}{2} \times \frac{\text{平均两两绝对差}}{\text{平均收入}} \quad (\text{3人样本取 } n(n-1)/2 = 3 \text{ 对})G=21​×平均收入平均两两绝对差​(3人样本取 n(n−1)/2=3 对)
    • 再分配关系：Disposable Income = Market Income −-− Direct Taxes +++ Cash Transfers。
    • 核对说明：Gini 系数恒位于 [0,1][0, 1][0,1] 区间；如果再分配后总收入不变而各人之间的差距缩小，Gini 系数应当下降。

3. 劳动纪律与就业租（Unit 6）

  • 识别词：incomplete contract、hidden action、employment rent、best response、efficiency wage
    • 核心公式（Unit 6 讲义）：
      Employment rent=w−wr−d(d=effort disutility)\text{Employment rent} = w - w_r - d \quad (d = \text{effort disutility})Employment rent=w−wr​−d(d=effort disutility)
    • 均衡条件：工人的最佳努力反应曲线（Best response curve, 充当企业面临的可行边界 MRT）与最陡的等成本射线（MRS）相切，在切点 MRS = MRT 处决定效率工资 w∗w^*w∗。在这个纳什均衡中存在非自愿失业——如果就业率为 100%、随时能无缝换到同等工作，失去工作的成本就会归零，效率工资机制也就无法维持。
    • 曲线移动：若失业救济或保留工资 wr↑w_r \uparrowwr​↑ 或努力负效用 d↑d \uparrowd↑，在同等工资下工人偷懒代价减小，Best response curve 整体向右移动，促使企业提高 w∗w^*w∗（单位努力成本上升）。
    • 注意事项：如果题干中的保留价值已经扣除了努力负效用，不要重复再减一次 ddd。

4. 定价企业利润最大化与弹性关系（Unit 7）

  • 识别词：MC、AC、MR = MC、CS / PS / Profit / DWL、elasticity、markup
    • 线性需求与边际收益：已知线性反需求 P=a−bQP = a - bQP=a−bQ，总收益为 aQ−bQ2aQ - bQ^2aQ−bQ2，求导可得 MR=a−2bQMR = a - 2bQMR=a−2bQ（纵截距相同，斜率翻倍）。
    • 切点条件与 MR = MC：等利润曲线与向下倾斜的需求曲线相切（MRS = MRT），等价于边际收益等于边际成本（MR=MCMR = MCMR=MC）。
    • AC 与 MC 的关系：只要平均成本高于边际成本（AC>MCAC > MCAC>MC），多生产一单位都会把平均值拉低（AC↓AC \downarrowAC↓）；只要 AC<MCAC < MCAC<MC，ACACAC 便上升；因此 MCMCMC 曲线从 ACACAC 的最低点穿过。
    • 剩余与经济利润：生产者剩余 PS=TR−∑MCPS = TR - \sum MCPS=TR−∑MC，企业净利润需扣除固定成本：Profit=PS−FC\text{Profit} = PS - FCProfit=PS−FC；无谓损失 DWLDWLDWL 是垄断产量 Q∗Q^*Q∗ 与竞争参考点 P=MCP = MCP=MC 之间的三角形损失。
    • 弹性与加成率：因为 MR=P(1−1/ε)MR = P(1 - 1/\varepsilon)MR=P(1−1/ε)，所以 MR>0MR > 0MR>0 只可能出现在需求富有弹性的区间（ε>1\varepsilon > 1ε>1）；在均衡处价格加成比 Markup=P−MCP=1ε\text{Markup} = \frac{P-MC}{P} = \frac{1}{\varepsilon}Markup=PP−MC​=ε1​，即加成率与需求弹性成反比。

5. 完全竞争、税收归宿与价格动态（Units 8, 11）

  • 识别词：price-taker、tax incidence、systematic risk、45° line、rent ceiling
    • 完全竞争长期均衡：短期利润最大化条件为 P=MCP = MCP=MC（此时可存在经济租）；长期允许企业自由进出，均衡会收敛至 P=MC=ACP = MC = ACP=MC=AC（经济租降为零）。
    • 税收归宿规律：对每单位商品征收从量税 ttt 会产生政府税收 tQ1tQ_1tQ1​ 与无谓损失 DWL=12t(Q0−Q1)DWL = \frac{1}{2} t (Q_0 - Q_1)DWL=21​t(Q0​−Q1​)。弹性较小的市场一侧难以通过大幅缩量来避税，因此更缺乏价格弹性的一方会承担更大比例的净税负。
    • 资产估值与两类风险：固定票息债券未来现金流固定，折现率（市场利率）上升会直接压低其现值（价格与利率反向变动）；分散投资可消除个股特质风险（Idiosyncratic risk），市场对资产回报率的定价仅反映不可分散的系统性风险（Systematic risk）。
    • 45° 价格动态稳定性：在 (Pt,Pt+1)(P_t, P_{t+1})(Pt​,Pt+1​) 图中，若价格动态曲线比 45° 线平缓（斜率 <1< 1<1），偏离均衡后会逐步收敛（Stable）；若针对可转售资产出现斜率 >1> 1>1 的动量正反馈，价格偏离会逐期放大（Unstable / Bubble）。
    • 限价配给机制：对不可转售的服务或租金设定低于出清价的上限（Rent ceiling），会导致超额需求、配给排队（Rationing）与黑市交易，属于非出清市场现象；需区分在均衡点持久存在的静态租（Static rent）与在出清过程中逐步消散的动态租（Dynamic rent）。
