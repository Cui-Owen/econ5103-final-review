核心公式与计算决策路由（考前必熟）

1. Economic Rent & 比较优势 & 等成本线（U2）

  • 识别词：next-best option、economic rent、sunk cost、comparative advantage、isocost slope
    • 必要公式：
Rent=Net benefit(chosen)−Net benefit(next-best)\text{Rent} = \text{Net benefit(chosen)} - \text{Net benefit(next-best)}Rent=Net benefit(chosen)−Net benefit(next-best)
C=wL+pR⇒等成本线斜率 =−wpC = wL + pR \Rightarrow \text{等成本线斜率 } = -\frac{w}{p}C=wL+pR⇒等成本线斜率 =−pw​
  • 操作步：先剔除不可追回的沉没成本；比较优势按“每产 1 单位 X 放弃多少 Y”的比值判谁更低；w/pw/pw/p 上升时等成本线变陡，转向少 LLL 多 RRR 技术。
  • 自检：绝对优势看产量绝对高低，比较优势看机会成本高低，一人不可能在两件产品上同时拥有比较劣势。

2. 约束优化 `MRS = MRT`、两效应与 Gini（U3–U5）

  • 识别词：MRS = MRT、income effect、substitution effect、Dominant / Nash / Pareto、Gini
    • 两效应口诀：预算线外移不改斜率 = Income Effect（正常品消费与闲暇均 ↑\uparrow↑）；斜率变陡 = Substitution Effect（闲暇变贵 ⇒\Rightarrow⇒ 闲暇 ↓\downarrow↓）。净变化符号看两者谁大。
    • Gini 讲义口径公式（2026 Week2 Friday.md 原式）：
G=12×平均两两绝对差平均收入(3人 n(n−1)/2=3 对)G = \frac{1}{2} \times \frac{\text{平均两两绝对差}}{\text{平均收入}} \quad (\text{3人 } n(n-1)/2 = 3 \text{ 对})G=21​×平均收入平均两两绝对差​(3人 n(n−1)/2=3 对)
  • 再分配关系：Disposable Income = Market Income −-− Direct Taxes +++ Cash Transfers。
  • 自检：Gini 恒在 [0,1][0, 1][0,1]；若税后总额不变而差距缩小，Gini 必降。

3. 劳动纪律与就业租（U6）

  • 识别词：incomplete contract、hidden action、employment rent、best response、efficiency wage
    • 核心公式（W3-1.md）：
Employment rent=w−wr−d(d=effort disutility)\text{Employment rent} = w - w_r - d \quad (d = \text{effort disutility})Employment rent=w−wr​−d(d=effort disutility)
  • 均衡条件：Best response curve (MRT) 与最陡 Isocost 射线 (MRS) 相切于 MRS = MRT ⇒w∗\Rightarrow w^*⇒w∗，且必存在非自愿失业（否则失业无代价）。
  • 曲线移动：救济金/保留工资 wr↑w_r \uparrowwr​↑ 或负效用 d↑d \uparrowd↑ ⇒\Rightarrow⇒ BR 右移 ⇒w∗↑\Rightarrow w^* \uparrow⇒w∗↑、单位努力成本 ↑\uparrow↑。
  • 避坑：若题面已将保留值折算为扣除付出后的净值，勿重复减 ddd。

4. 定价企业利润最大化与福利弹性（U7）

  • 识别词：MC、AC、MR = MC、CS / PS / Profit / DWL、elasticity、markup
    • 线性需求速算法：给定 P=a−bQP = a - bQP=a−bQ，边际收益必为 MR=a−2bQMR = a - 2bQMR=a−2bQ（斜率翻倍）。
    • 切点等价律：Isoprofit 与需求相切（MRS = MRT）   ⟺  \iff⟺ MR=MCMR = MCMR=MC。
    • 成本铁律：AC>MC⇒AC↓AC > MC \Rightarrow AC \downarrowAC>MC⇒AC↓；AC<MC⇒AC↑AC < MC \Rightarrow AC \uparrowAC<MC⇒AC↑；MCMCMC 必从最低点穿过 ACACAC。
    • 剩余与利润：PS=TR−∑MCPS = TR - \sum MCPS=TR−∑MC，Profit=PS−FC\text{Profit} = PS - FCProfit=PS−FC；DWLDWLDWL 是 (Q∗,P∗)(Q^*, P^*)(Q∗,P∗) 到 (Qc,MC)(Q_c, MC)(Qc​,MC) 之间的三角损失。
    • 弹性与加成：MR>0  ⟺  ε>1MR > 0 \iff \varepsilon > 1MR>0⟺ε>1（富弹性）；Markup=P−MCP\text{Markup} = \frac{P-MC}{P}Markup=PP−MC​ 与 ε\varepsilonε 成反比（线性单品均衡处 Markup=1/ε\text{Markup} = 1/\varepsilonMarkup=1/ε）。

5. 竞争均衡、税收归宿与价格稳定（U8 & U11）

  • 识别词：price-taker、tax incidence、systematic risk、45° line、rent ceiling
    • 竞争长期均衡：短期 P=MCP = MCP=MC（可赚租）；长期自由进出使 P=MC=ACP = MC = ACP=MC=AC（经济租归零）。
    • 税收归宿铁律：单位税 ttt 使总剩余产生 DWL=12t(Q0−Q1)DWL = \frac{1}{2} t (Q_0 - Q_1)DWL=21​t(Q0​−Q1​) 与税收 tQ1tQ_1tQ1​；更缺乏弹性的一方承担更多税负（并在税前原本享有更高剩余份额）。
    • 资产与风险：债券固定付款 ⇒\Rightarrow⇒ 价格与利率反向；组合分散仅消除 Idiosyncratic risk，真正决定市价资本化率的是 Systematic risk。
    • 45° 价格动态判稳：曲线比 45° 线平缓（斜率 <1< 1<1）⇒\Rightarrow⇒ Stable；比 45° 线陡（斜率 >1> 1>1）且商品可转售 ⇒\Rightarrow⇒ Unstable / Bubble。
    • 限价非泡沫：Rent ceiling（低于出清价）导致 Excess demand + Rationing + Secondary market，区分 Static rent（均衡持续）与 Dynamic rent（向均衡消散）。

例 1（U5 原文例题）：三人收入 y = (12, 4, 2) 的 Gini 系数

  • 完整推演（依据 2026 Week2 Friday.md PDF 第 16 页）：
    1. 两两无序配对绝对差（n(n−1)/2=3n(n-1)/2 = 3n(n−1)/2=3 对）：∣12−4∣=8|12-4|=8∣12−4∣=8，∣12−2∣=10|12-2|=10∣12−2∣=10，∣4−2∣=2|4-2|=2∣4−2∣=2。
    2. 平均绝对差：(10+8+2)/3=20/3≈6.67(10 + 8 + 2)/3 = 20/3 \approx 6.67(10+8+2)/3=20/3≈6.67。
    3. 平均收入：yˉ=(12+4+2)/3=6\bar{y} = (12 + 4 + 2)/3 = 6yˉ​=(12+4+2)/3=6。
    4. Gini 系数：G=12×6.676=20/66=59≈0.56G = \frac{1}{2} \times \frac{6.67}{6} = \frac{20/6}{6} = \frac{5}{9} \approx 0.56G=21​×66.67​=620/6​=95​≈0.56。
